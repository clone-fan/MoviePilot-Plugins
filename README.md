# 媒体融合 Signal

> 通知汇报、数据监控、下载管理、系统维护、插件卸载，你要的全在里面。

MoviePilot 运维一体化插件。把散落在十几个插件里的通知汇报、数据监控、下载管理、系统维护和插件卸载全部收进一个面板，统一调度、统一风格、统一管理。

## 功能概览

- **通知汇报** — 每日汇报聚合日报 + Telegram 融合汇报卡，一站看完站点状态、下载、订阅、健康、存储和媒体动态
- **数据监控** — 站点数据统计（上传/下载/分享率/魔力）、存储空间巡查、数据库健康、目录权限检查
- **下载管理** — 自动删种、下载器助手（活动种子概览 + 按站点批量打标签）、订阅规则自动填充
- **系统维护** — 日志清理、自动备份与恢复、MoviePilot 更新推送、插件库更新检查
- **插件卸载** — 接入 MoviePilot 官方卸载流程，清理配置/数据/日志/残留文件

## 安装

在 MoviePilot 插件市场搜索「媒体融合 Signal」安装，或手动将 plugins.v2/signal/ 目录放入 MoviePilot 插件目录。
