# 汇报栏目与组件对应关系

每日汇报是聚合中心，配置页「汇报栏目」只控制栏目是否出现在日报中；具体能力归属到对应组件。

| 栏目 ID | 日报栏目 | 对应组件 | 依赖开关 | 说明 |
|--------|----------|----------|----------|------|
| report_version | MoviePilot 版本 | 每日汇报 | 无 | 前后端版本信息 |
| report_site_status | 站点状态 | 站点数据统计 | 无 | 各站点状态 |
| report_site_increment | 站点增量 | 站点数据统计 | site_stat_enabled | 上传、下载、分享率、魔力 |
| report_today_download | 今日下载 | 下载入库 | 无 | 今日已下载入库明细 |
| report_transfer | 入库整理 | 下载入库 | 无 | 今日入库成功/失败 |
| report_subscribe | 订阅追新 | 订阅追新 | subscribe_reminder_enabled | 今日追新内容 |
| report_storage | 存储空间 | 存储空间 | 无 | 下载/媒体目录用量 |
| report_media_stat | 媒体统计 | 媒体库 | 无 | 电影、电视剧、剧集、用户统计 |
| report_health | 健康巡查 | 健康巡查 | health_check_enabled | 最近一次健康巡查结果 |
| report_summary | 今日摘要 | 每日汇报 | 无 | 前文摘要 |

## 归纳规则

- 「订阅追新」统一替代旧 UI 文案「订阅提醒」；旧配置键保持兼容。
- 「站点状态」和「站点增量」都归属「站点数据统计」组件。
- 「今日下载」和「入库整理」都归属「下载入库」口径，避免再单独重复展示下载器段。
- 「健康巡查」只在「汇报栏目」控制是否并入日报；健康巡查组件页只配置巡查本身。
- 维护类动作（备份、日志清理、更新检查、残留清理、自动删种）默认不进入日报，除非后续新增统一的「维护任务」栏目。
